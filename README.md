# 🧠 Tic Tac Toe – Neo Edition
*A futuristic AI-powered Tic Tac Toe game built with Python & PyQt5.*

## 🎮 About the Project

**Tic Tac Toe – Neo Edition** is a modern, stylish remake of the classic Tic Tac Toe game, developed in **Python** using **PyQt5** for the GUI. It features a futuristic Matrix-inspired theme and a smart AI opponent with three levels of difficulty. This project combines clean design, responsive user interface, and an intelligent decision-making algorithm.

---

## ✨ Features

- 🧑‍💻 **Player vs AI**: Human player (X) vs system-controlled AI (O).
- 🧠 **Three AI Difficulty Levels**:
  - **Easy** – Random moves.
  - **Medium** – Blocks player and looks for winning moves.
  - **Hard** – Implements the unbeatable **Minimax algorithm**.
- 🎨 **Custom Neo-style UI**:
  - Matrix-inspired dark theme with green neon fonts.
  - Stylish buttons, status display, and hover effects.
- 🔄 **Game Mechanics**:
  - Real-time win/tie detection.
  - Smooth turn switching.
  - One-click board reset.
- 🧺 **Well-structured OOP codebase**, easy to maintain and extend.


---

## 🧠 How the AI Works

- **Easy Mode**: Chooses a random empty cell.
- **Medium Mode**: Tries to win or block the opponent from winning.
- **Hard Mode**: Uses the **Minimax algorithm**, a recursive AI decision-making process that simulates all possible game outcomes and picks the optimal move.
